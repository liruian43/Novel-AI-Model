了解如何使用 InkOS Studio

快速入门

ℹ️ 首次使用请先在"配置管理"页面设置 LLM API 配置
  1. 配置 API - 在配置管理页面填写您的 API Key 和模型信息
  2. 创建书籍 - 在书籍管理页面点击"创建新书"，填写书名、题材等信息
  3. 开始写作 - 在智能写作页面选择书籍，设置参数后点击"开始写作"
  4. 审阅章节 - 在章节审阅页面查看生成的草稿和审计报告
  5. 批准或修订 - 对满意的章节点击"批准"，需要修改的点击"修订"

核心功能说明

📡 雷达扫描

扫描平台趋势和读者偏好，指导故事方向。可插拔，可跳过。

🏗️ 建筑师规划

规划章节结构：大纲、场景节拍、节奏控制。

✍️ 写手写作

根据大纲 + 当前世界状态生成正文内容。

👁️ 审计员审查

32 维度连续性审计，包括 OOC 检查、时间线、战力崩坏等。

🔧 修订者优化

修复审计发现的问题，支持 spot-fix 定点修复模式。

🔍 AIGC 检测

AI 痕迹检测与反检测改写，降低 AI 文本特征。

常见问题

Q: 如何更换 API 提供商？

A: 在配置管理页面选择对应的服务商，填写相应的 API Key 和 Base URL 即可。

Q: 通义千问如何配置？

A: 选择"阿里云通义千问 (Qwen)"，Base URL 会自动填充为阿里云地址。模型可选择 qwen-plus、qwen-max 或 qwen-turbo。需要在阿里云百炼平台申请 API Key。

Q: 自定义大模型如何使用？

A: 选择"自定义大模型 (OpenAI 兼容)"，然后填写您的自定义 API 地址、API Key 和模型名称。适用于任何兼容 OpenAI 接口格式的本地部署模型或其他第三方服务。

Q: 什么是题材 (Genre)？

A: 题材是小说类型分类，如玄幻、仙侠、都市等。每个题材有专属的创作规则、禁忌清单和审计维度。

Q: 如何导出小说内容？

A: 在书籍管理页面，点击书籍卡片上的"导出"按钮，可选择导出为 TXT 或 Markdown 格式。

Q: 文风仿写如何使用？

A: 在文风仿写页面上传参考文本（建议 5000 字以上），系统会分析句长、词汇多样性等特征，然后应用到目标书籍。
