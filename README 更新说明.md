## 🔍 关键说明

### 关于真相文件

README 中详细解释了两种实现方式的差异：

**CLI 项目**（真实文件）：
```
books/
└── 吞天魔帝/
    └── state/
        ├── current_state.md       ← 真实 MD 文件
        └── ...                    ← 7 个文件
```

**HTML 应用**（LocalStorage）：
```javascript
localStorage {
  "truthFiles": {
    "book_xxx": {
      "current_state.md": "# 内容...",
      // ... 7 个文件
    }
  }
}
```

**同步策略**：
- ✅ 支持导出为 ZIP（包含所有 MD 文件）
- ✅ 支持从 ZIP 导入
- ⚠️ 不会自动同步到磁盘
